# 🏦 نظام تفصيلي حسابات مراكز التكلفة

نظام محاسبي لإدارة وتفصيل حسابات مراكز التكلفة، مخصص لجمعية تراؤف مع لوحة فلاتر ديناميكية ومطابقة للمعايير المحاسبية.

## 🌟 المميزات الرئيسية
- **لوحة فلاتر احترافية**:
  - فلترة حسب مركز التكلفة والحساب المالي.
  - فلتر مخصص للمصروفات غير المربوطة بمراكز التكلفة (مع عدّاد مباشر وإبراز بصري).
  - فلتر البحث في المبالغ (نطاقات مبالغ وحد أدنى/أعلى).
  - فلاتر التاريخ (فترات سريعة وتحديد يدوي).
  - بحث نصي فوري في الشرح ورقم المستند والقيد.
- **إحصائيات وإجماليات لحظية**:
  - احتساب إجمالي المدين والدائن والرصيد التراكمي وعدد الحركات فورياً.
- **تصدير وطباعة**:
  - تصدير فوري إلى Excel (CSV يدعم العربية UTF-8).
  - دعم الطباعة المباشرة مع إخفاء أدوات التحكم تلقائياً.

## 💻 التقنيات المستخدمة
- HTML5 / CSS3 (تصميم محاسبي بدون أطر عمل خارجية)
- Vanilla JavaScript
- دعم كامل للعربية (RTL) مع خط Tajawal و Material Symbols
